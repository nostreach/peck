What this site tests

This test site exercises the peck tunnel with the following:

  • Multiple HTML pages with in-page navigation
  • External CSS and JS assets
  • Inline images (SVG)
  • JSON API endpoint
  • Form POST submission
  • HTTP 302 redirect
  • Custom 404 error page
  • Large content (100 paragraphs of lorem ipsum)

If you can navigate between pages, submit the form, and see the clock ticking on the home page, the tunnel handles real web traffic correctly.

How peck works

  1. Browser generates ephemeral Nostr keypair
  2. Browser publishes encrypted DM (NIP-04) to Nostr relay
  3. Daemon receives DM, responds with WebRTC SDP offer
  4. Browser and daemon exchange ICE candidates
  5. WebRTC peer connection established (hole-punched through NAT)
  6. HTTP requests multiplexed over DataChannel
