what this site tests

  • Multiple HTML pages with in-page navigation
  • External CSS and JS assets
  • Inline images (SVG)
  • JSON API endpoint
  • Form POST and GET submissions
  • HTTP 302 redirect
  • Custom 404 error page
  • Large content (100 paragraphs of lorem ipsum)

If you can navigate between pages, submit the form, and see the clock ticking on the home page, the tunnel handles real web traffic correctly.

how peck works

  1. Browser generates an ephemeral Nostr keypair
  2. Browser publishes an encrypted NIP-44 DM to a Nostr relay
  3. Daemon receives the DM and answers with a WebRTC SDP offer
  4. Both sides exchange ICE candidates
  5. WebRTC peer connection is established (NAT hole-punched)
  6. HTTP requests are multiplexed over the DataChannel
